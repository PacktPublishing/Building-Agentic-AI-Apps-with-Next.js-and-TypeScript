# Contextual Retrieval

## The Problem: Lost Context

When we chunk documents for embedding, each chunk loses its surrounding context.

**Example:**

```
Original Trip Document:
"7-day luxury trip to Barcelona, Spain for 2 adults.
 Total budget: €4500. Includes 5-star hotel,
 Michelin restaurant reservations, and private tours.

 The hotel costs €150 per night and includes breakfast."
```

After chunking:
```
Chunk 1: "7-day luxury trip to Barcelona, Spain for 2 adults..."
Chunk 2: "The hotel costs €150 per night and includes breakfast."
```

**Chunk 2 is now ambiguous:**
- Which trip is this about?
- What hotel?
- What budget tier?

This **lost context** hurts retrieval quality.

---

## The Solution: Contextual Retrieval

Add a **contextual prefix** to each chunk before embedding.

```
Before (isolated chunk):
"The hotel costs €150 per night and includes breakfast."

After (contextualized):
"This 7-day premium trip to Barcelona, Spain for 2 adults with a €4500 budget includes:
 The hotel costs €150 per night and includes breakfast."
```

Now the embedding captures the full context!

export interface ContextualChunk {

### Context Generation Prompt

```typescript
const CONTEXT_SYSTEM_PROMPT = `You are a context generator for a travel search database.
Given a trip's metadata and a text chunk from that trip, generate a brief contextual
prefix that situates the chunk within the full trip context.

The prefix should:
1. Be concise (1 sentence, ~20-30 words max)
2. Include key identifying information (destination, duration, budget tier)
3. Help a search system understand what trip this chunk belongs to
4. Be written in a natural, descriptive style

Format: [Context sentence]

Example:
Chunk: "The hotel costs €150 per night and includes breakfast."
Context: "This 7-day premium trip to Barcelona, Spain for 2 adults with a €4500 budget includes:"`;
```

### Contextual Chunker Class

```typescript
export class ContextualChunker {
  private llm: ChatAnthropic;
  private cache: Map<string, string> = new Map();
  private useCache: boolean;
  private rateLimitDelay: number;

  constructor(config: ContextualChunkerConfig = {}) {
    this.llm = new ChatAnthropic({
      modelName: config.model || 'claude-3-haiku-20240307',
      temperature: 0,
    });
    this.useCache = config.useCache ?? true;
    this.rateLimitDelay = config.rateLimitDelay ?? 100;
  }

  /**
   * Add contextual prefix to a chunk
   */
  async addContext(
    chunk: string,
    tripContext: TripContext,
    chunkId: string
  ): Promise<ContextualChunk> {
    const cacheKey = `${tripContext.tripId}:${chunkId}`;

    // Check cache
    if (this.useCache && this.cache.has(cacheKey)) {
      const cachedPrefix = this.cache.get(cacheKey)!;
      return {
        originalText: chunk,
        contextPrefix: cachedPrefix,
        contextualText: `${cachedPrefix} ${chunk}`,
        chunkId,
        documentId: tripContext.tripId,
      };
    }

    // Generate context with LLM
    const contextPrefix = await this.generateContextPrefix(chunk, tripContext);

    // Cache the result
    if (this.useCache) {
      this.cache.set(cacheKey, contextPrefix);
    }

    return {
      originalText: chunk,
      contextPrefix,
      contextualText: `${contextPrefix} ${chunk}`,
      chunkId,
      documentId: tripContext.tripId,
    };
  }

  private async generateContextPrefix(
    chunk: string,
    tripContext: TripContext
  ): Promise<string> {
    const tripSummary = `
Trip: ${tripContext.title}
Destination: ${tripContext.destination}
From: ${tripContext.departureCity}
Duration: ${tripContext.stayDuration} days
Travelers: ${tripContext.numPeople} people
Budget: ${tripContext.budgetCategory} (€${tripContext.totalBudget})
Date: ${tripContext.departureDate}
    `.trim();

    const response = await this.llm.invoke([
      new SystemMessage(CONTEXT_SYSTEM_PROMPT),
      new HumanMessage(
        `Trip metadata:\n${tripSummary}\n\nChunk:\n"${chunk}"\n\nGenerate a contextual prefix:`
      ),
    ]);

    let prefix = typeof response.content === 'string'
      ? response.content.trim()
      : '';

    // Clean up the prefix
    prefix = prefix.replace(/^\[|\]$/g, '').trim();

    return prefix;
  }
}
```

### Batch Processing with Rate Limiting

```typescript
/**
 * Process multiple chunks with rate limiting
 */
async addContextBatch(
  chunks: Array<{ text: string; chunkId: string }>,
  tripContext: TripContext
): Promise<ContextualChunk[]> {
  const results: ContextualChunk[] = [];

  for (let i = 0; i < chunks.length; i++) {
    const chunk = chunks[i];
    const result = await this.addContext(chunk.text, tripContext, chunk.chunkId);
    results.push(result);

    // Rate limiting between calls
    if (i < chunks.length - 1 && this.rateLimitDelay > 0) {
      await new Promise((resolve) => setTimeout(resolve, this.rateLimitDelay));
    }
  }

  return results;
}
```

### Simple Context (Fast Fallback)

```typescript
/**
 * Generate a simple context prefix without LLM (fast fallback)
 */
generateSimpleContext(tripContext: TripContext): string {
  return `[${tripContext.stayDuration}-day ${tripContext.budgetCategory} trip to ${tripContext.destination} for ${tripContext.numPeople} from ${tripContext.departureCity}, €${tripContext.totalBudget} budget]`;
}
```

## Usage

### Single Chunk

```typescript
import { ContextualChunker } from '@/lib/infrastructure/chunking/contextual-chunker';

const chunker = new ContextualChunker();

const tripContext: TripContext = {
  tripId: 'trip-123',
  title: 'Barcelona Beach Getaway',
  destination: 'Barcelona',
  departureCity: 'Paris',
  departureDate: '2024-07-15',
  stayDuration: 7,
  numPeople: 2,
  budgetCategory: 'premium',
  totalBudget: 4500,
};

const chunk = 'The hotel costs €150 per night and includes breakfast.';

const contextual = await chunker.addContext(chunk, tripContext, 'chunk-1');

console.log(contextual.contextualText);
// "This 7-day premium trip to Barcelona, Spain for 2 adults with a €4500 budget includes:
//  The hotel costs €150 per night and includes breakfast."
```

### Batch Processing

```typescript
const chunks = [
  { text: 'The hotel is located in the Gothic Quarter.', chunkId: 'c1' },
  { text: 'Day 1: Visit La Sagrada Familia.', chunkId: 'c2' },
  { text: 'Dinner at a Michelin-starred restaurant.', chunkId: 'c3' },
];

const contextualChunks = await chunker.addContextBatch(chunks, tripContext);

for (const c of contextualChunks) {
  console.log(`\n${c.chunkId}:`);
  console.log(`  Original: ${c.originalText}`);
  console.log(`  Contextual: ${c.contextualText}`);
}
```

### Using Simple Context (No LLM)

```typescript
// For speed-critical scenarios or cost optimization
const simpleContext = chunker.generateSimpleContext(tripContext);
console.log(simpleContext);
// "[7-day premium trip to Barcelona for 2 from Paris, €4500 budget]"

// Use manually
const contextualText = `${simpleContext} ${chunk}`;
```

## Reindexing Strategy

To use contextual retrieval, you need to reindex your documents:

```typescript
// scripts/reindex-with-context.ts

async function reindexWithContext() {
  const chunker = new ContextualChunker();
  const embeddingsService = new OpenAIEmbeddingsService();
  const vectorRepository = new QdrantVectorRepository();

  // Fetch all trips from database
  const trips = await fetchAllTrips();

  for (const trip of trips) {
    // Split trip into chunks
    const chunks = splitIntoChunks(trip.description);

    // Add context to each chunk
    const tripContext: TripContext = {
      tripId: trip.id,
      title: trip.title,
      destination: trip.destination,
      // ... other fields
    };

    const contextualChunks = await chunker.addContextBatch(
      chunks.map((text, i) => ({ text, chunkId: `${trip.id}-${i}` })),
      tripContext
    );

    // Embed and store
    for (const chunk of contextualChunks) {
      const embedding = await embeddingsService.generate(chunk.contextualText);
      await vectorRepository.upsert({
        id: chunk.chunkId,
        vector: embedding,
        payload: {
          original_text: chunk.originalText,
          contextual_text: chunk.contextualText,
          trip_id: trip.id,
          destination: trip.destination,
          // ... other metadata
        },
      });
    }
  }
}
```

## LLM vs Simple Context

| Aspect | LLM Context | Simple Context |
|--------|-------------|----------------|
| **Quality** | High (natural language) | Medium (template) |
| **Speed** | Slow (~100ms/chunk) | Fast (~0ms/chunk) |
| **Cost** | ~$0.0001/chunk (Haiku) | Free |
| **Flexibility** | Adapts to content | Fixed format |

### When to Use Each

**LLM Context:**
- Initial indexing (done once)
- High-value documents
- When quality is critical

**Simple Context:**
- Real-time applications
- Cost-sensitive scenarios
- Development/testing

## Best Practices

### 1. Cache Aggressively

Context generation is deterministic for same inputs:

```typescript
const chunker = new ContextualChunker({ useCache: true });

// Second call returns cached result
await chunker.addContext(sameChunk, sameContext, sameId);
```

### 2. Batch Processing for Indexing

```typescript
// Good: Process in batches with rate limiting
const contextualChunks = await chunker.addContextBatch(chunks, tripContext);

// Avoid: Individual calls in tight loop
for (const chunk of chunks) {
  await chunker.addContext(chunk, ...); // No rate limiting!
}
```

### 3. Store Both Original and Contextual Text

```typescript
// In your vector DB payload
{
  original_text: chunk.originalText,      // For display
  contextual_text: chunk.contextualText,  // What was embedded
  context_prefix: chunk.contextPrefix,    // The context alone
}
```

### 4. Handle Failures Gracefully

```typescript
try {
  return await this.addContext(chunk, context, id);
} catch (error) {
  // Fallback to simple context or no context
  return {
    originalText: chunk,
    contextPrefix: this.generateSimpleContext(context),
    contextualText: `${this.generateSimpleContext(context)} ${chunk}`,
    chunkId: id,
    documentId: context.tripId,
  };
}
```

Key findings:

---

## Key Takeaways

1. **Chunks lose context** when separated from their document
2. **LLM-generated prefixes** add back the missing context
3. **Context is embedded** with the chunk for better matching
4. **Simple context** is a fast fallback when LLM is too slow
5. **Reindexing required** to apply contextual retrieval
6. **Store both** original and contextual text for flexibility
